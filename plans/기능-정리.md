# 플랜위브(PlanWeave) — 개정 04 요약

제품명 제안은 계획과 기록을 엮는다는 의미의 플랜위브(PlanWeave)다. 상표·도메인 사용 가능 여부는 미확인이다.

상세 기준은 같은 폴더의 [개발 기획서](개발-기획서.md)에 정리했다.

- 왼쪽: 프로젝트 폴더와 프로젝트 목록. 상단 토글로 사이드바 전체를 접고 펼친다.
- 중앙 왼쪽: 계층형 WBS 작업명과 그룹 접기.
- 중앙 오른쪽: 각 작업의 시작일부터 종료일까지 표시하는 가로 막대.
- 일정 영역 Ctrl+휠 업은 확대, Ctrl+휠 다운은 축소. 포인터 아래 날짜를 유지한다.
- 시간 눈금은 일·주·월·분기·년으로 자동 전환한다. 상단 날짜 입력·단위 선택·줌 슬라이더·줌 버튼은 제거한다.
- 시간 이동은 일반 휠, 수평 스크롤 또는 일정 빈 공간 드래그로 한다. 일반 휠 위는 과거, 아래는 미래로 이동한다. 작업명 영역의 휠은 행 세로 스크롤에 사용한다.
- 작업 상세의 실제 시작일·종료일 입력은 유지한다. 보기 확대·축소는 작업 일정을 변경하지 않는다.
- 막대 호버는 별도 작성한 요약, 더블클릭은 개요·기간·자유 배치 보드·상세 문서를 표시한다.
- 프로젝트 상세에서 문서를 개수 제한 없이 추가한다. 문서가 창 높이를 넘으면 내부를 세로 스크롤하며 상단 버튼은 고정한다.
- 일반 작업 막대를 좌우로 드래그하면 기간 길이를 유지하며 시작일·종료일을 함께 이동한다. 그룹 요약 막대는 직접 이동하지 않는다.
- 작업별 일정 잠금은 막대 이동과 상세 날짜 편집을 막는다. 이름·노트·문서 편집은 가능하며 잠금 상태는 저장한다.

동봉 HTML은 개정 02의 조작 검토용 시안이며 개정 03~04의 변경은 반영하지 않았다. 실제 제품의 입력·문서·일정 이동·잠금·저장·검증 기준은 상세 기획서를 따른다.
